## CSV は「表」のテキスト

CSV は、**表をただの文字で表したファイル**です。1行目が見出し、2行目からがデータで、列はカンマで区切ります。Excel で「CSV として保存」したときにできるのもこの形式です（Excel 専用の `.xlsx` と違い、中身はメモ帳でも読める素のテキストです）。

まず練習用のファイルを作ります。エディタで `python-practice` の中に `items.csv` を作り、次の内容を貼り付けて保存してください（VSCode なら既定で UTF-8 という文字コードで保存されます。そのままで大丈夫です）。

```text
name,stock,place
モニター,4,倉庫A
キーボード,12,倉庫B
ケーブル,2,倉庫A
```

「備品が3件、それぞれ在庫数と置き場所を持つ」小さな表です。

## 読む——csv.DictReader

このファイルを Python で読みます。`convert.py` を作り、`python-practice` の中で（`items.csv` と同じ場所で）`uv run convert.py` として実行してください。別の場所から実行すると、ファイルが見つからず `FileNotFoundError` になります。

```python
import csv

with open("items.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

print(rows[0])
print(len(rows))
```

```text
{'name': 'モニター', 'stock': '4', 'place': '倉庫A'}
3
```

出力を見てください——**見覚えのある形**ではないでしょうか。1行目のデータが**辞書**に、全体が**辞書のリスト**になっています。前のコースで「表の1行=辞書、表全体=リスト」と伏線を張った、その回収がこの `csv.DictReader` です。見出し行が自動でキー（名札）になります。

新しい書き方を3つ押さえます。

- `import csv` — CSV を扱う標準の分冊（モジュール）を取り寄せる。前のレッスンと違い今回は分冊ごと取り寄せて、中の手順は `csv.DictReader` のように**ドットでつないで**呼びます
- `with open(...) as f:` — ファイルを開き、インデントの中が終わったら自動で閉じる決まり文句。`encoding="utf-8"` は文字コードの指定です
- `list(...)` — DictReader が返すものをリストに変換します。`int()` や `str()` と同じ、変換の仲間です

> [!TIP]
> 日本語が文字化けしたり `UnicodeDecodeError` が出たりしたら、`encoding="cp932"` に変えて試してください。Excel などは UTF-8 と別の文字コードで保存することがあります。

もう1つ、出力をよく見ると `'stock': '4'` と**数字が引用符付き**です。**CSV から読んだ値はぜんぶ文字列（str）になります。** 数として使うには `int()` で変換する——「変数と型」のレッスンで覚えた、あの変換の出番です。

## 加工する——条件で絞り込む

読めれば、あとは文法基礎コースの道具がそのまま使えます。在庫が5個未満のものだけを集めてみます。次のコードは `convert.py` の**続きに足して**ください（`rows` を使うので、別ファイルでは動きません）。

```python
low = []
for row in rows:
    if int(row["stock"]) < 5:
        low.append(row)

print(len(low))
```

```text
2
```

（前の節の print も一緒に出ます。ここでは新しく増えた行だけ載せています。以降の節も同じです。）

`for` で1行ずつ取り出し、`if` で条件に合うものだけを新しいリストに `append` する——全部、すでに知っている部品です。`int(...)` を忘れると `'4' < 5` の比較になりエラーで止まるので、そこだけ気をつけてください。

## 書き出す——json.dump

最後に、絞り込んだ結果を JSON ファイルに書き出します。JSON は、**リストや辞書の入れ子をそのままの形で保存できる**テキスト形式で、ツールの出力形式の定番です。これも `convert.py` の続きに足します（`import json` はファイルの先頭、`import csv` の隣に置くのが慣例です）。

```python
import json

with open("low_stock.json", "w", encoding="utf-8") as f:
    json.dump(low, f, ensure_ascii=False, indent=2)

print(f"{len(low)}件を書き出しました")
```

実行すると `low_stock.json` ができています。開いてみてください。

```json
[
  {
    "name": "モニター",
    "stock": "4",
    "place": "倉庫A"
  },
  {
    "name": "ケーブル",
    "stock": "2",
    "place": "倉庫A"
  }
]
```

Python の「辞書のリスト」が、ほぼ見た目そのままファイルになりました。`open` の `"w"` は書き込みモードの指定です。`ensure_ascii=False` は日本語をそのまま書くため、`indent=2` は人が読みやすいよう字下げするための指定で、**この2つはいつも付ける決まり文句**と覚えて構いません。

在庫数が `"4"` と文字列のままなのが気になった人へ——**書き出しは元の形のままで構いません**。数に変換したのは比較のためで、保存する形まで変える必要はありません（数として保存したくなったら、書き出す前に入れ直せます）。

_出典: [Python 公式ドキュメント「json — JSON エンコーダおよびデコーダ」](https://docs.python.org/ja/3/library/json.html)（2026年8月取得）_

なぜ CSV で書き出さないのか？と思った人へ——CSV は平らな表しか表せませんが、JSON は入れ子（リストの中に辞書、辞書の中にリスト）をそのまま書けます。今回の結果はまだ表の形なので CSV でも書けますが、加工を重ねると（置き場ごとにまとめる、など）表に収まらない形になっていきます。そうなっても書き方を変えずに済むのが JSON で、**入力は CSV、出力は JSON** という組み合わせが実務では定番です。

## まとめ

このレッスンの骨は3つです。

1. CSV は `csv.DictReader` で読むと**辞書のリスト**になる。ただし**値はぜんぶ文字列**——数にするなら `int()`
2. 加工は文法基礎コースの部品（for・if・append）がそのまま使える
3. 書き出しは `json.dump`。**入力は CSV、出力は JSON** が実務の定番

「読む → 加工する → 書き出す」が一本つながりました。これがあなたの書く業務ツールの背骨です。次はシリーズ最後のレッスン——既製品の道具を取り寄せて、この流れをさらに楽にします。

## 確認問題

1. `csv.DictReader` で読んだ在庫数をそのまま `< 5` と比較するとエラーになります。なぜか、「型」という言葉を使って説明してみてください。
2. 出力に CSV ではなく JSON を使う利点を、「入れ子」という言葉を使って1文で言ってみてください。
