# 外部ライブラリを使う

## 学習目標

Python基礎シリーズ、最後のレッスンです。締めくくりに、**既製品の道具（ライブラリ）を取り寄せて使う**方法を覚えます。題材は **pandas（パンダス）**——表データ処理の、いわば**表計算の専用機**にあたる定番ライブラリです。

前のレッスンで CSV を1行ずつ読んで加工しました。pandas を使うと、同じことがさらに短く書けます。終わる頃には、`uv add` で道具を調達し、pandas で CSV を読んで簡単な集計までできるようになっています。

## 既製品の道具を調達する——uv add

「全部自分で書くのか？」——書きません。表の集計のようなよくある仕事には、世界中の開発者が磨いてきた既製品の道具があります。それを取り寄せるのも**調達係（uv）の仕事**です。

`python-practice` の中で、次を実行してください。

```powershell
uv add pandas
```

```text
Resolved 6 packages in 34ms
Installed 5 packages in 1.18s
 + numpy==2.5.2
 + pandas==3.0.5
 + python-dateutil==2.9.0.post0
 + six==1.17.0
 + tzdata==2026.3
```

数秒で完了します（バージョンの数字は違っていて構いません）。注目してほしいのは **Installed の行**——頼んだのは pandas 1つなのに**5つ入った**ことです（1行目の Resolved の数は気にしなくて構いません）。pandas が動くために必要な他の道具まで、調達係がまとめて手配してくれています。手作業の環境構築でいちばん壊れやすいのがこの「芋づるの依存関係」で、uv を使う理由がここにあります。

入った先は、このプロジェクト専用の**道具置き場**（`python-practice` の `.venv`）です。PC 全体に入るわけではないので、別のプロジェクトで pandas を使うときは、そこでもう一度 `uv add pandas` をします。

なお、`import csv` や `import json` で取り寄せた道具は Python に最初から同梱されているので `uv add` は不要でした。**同梱されていない道具のときだけ `uv add`**——この区別だけ覚えてください。

## pandas で読む

前のレッスンの `items.csv`（備品3件の表）を、今度は pandas で読んでみます。`python-practice` の中に新しいファイル（`bunseki.py` など）を作り、次を書いて `uv run bunseki.py` で実行してください（以降のコードはこのファイルの続きに足していきます）。

```python
import pandas as pd

df = pd.read_csv("items.csv")
print(len(df))
print(list(df.columns))
```

```text
3
['name', 'stock', 'place']
```

`import pandas as pd` は「pandas を `pd` という短い呼び名で取り寄せる」という意味で、世界共通の慣例です。`pd.read_csv` は、ファイルを開いて閉じるところまで含めて**1行で表を読み込みます**。前のレッスンの読み込みと並べると、短さが見えます（中身は読み返さなくて構いません。**行数の差**だけ見てください）。

```python
# 標準の csv での読み込み（前のレッスン）
with open("items.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

# pandas での読み込み
df = pd.read_csv("items.csv")
```

読んだ結果 `df` は **DataFrame（データフレーム）** という「表まるごと」のデータで、`len()` で行数、`list(df.columns)` で列名が取れます。DataFrame の中の仕組みは、いまは知らなくて大丈夫です。

中身を見たいときは `head()` です。

```python
print(df.head())
```

```text
    name  stock place
0   モニター      4   倉庫A
1  キーボード     12   倉庫B
2   ケーブル      2   倉庫A
```

表がそのまま表示されました。左端の 0・1・2 は pandas が付けた行番号です（リストの番号と同じ 0 始まり）。

## 集計する

pandas の得意技を2つだけ見ます。まず、**列の値を数える** `value_counts`。

```python
print(df["place"].value_counts())
```

```text
place
倉庫A    2
倉庫B    1
Name: count, dtype: int64
```

「置き場所ごとに何件あるか」が1行で出ました。`df["列名"]` で列を取り出す書き方は、辞書の名札引きと同じ形です。表示の最後の `Name: count, dtype: int64` はいまは読み飛ばして構いません。

もう1つ、**数の列の合計**。

```python
print(df["stock"].sum())
```

```text
18
```

ここで前のレッスンとの違いに気づいたでしょうか。`csv.DictReader` では在庫数が文字列で読まれ、`int()` の変換が必要でした。**pandas は数字の列を自動で数として読みます**。だからそのまま合計できるのです。

このレッスンで触れるのはここまでです。pandas には並べ替え・グループ集計・欠損値処理など道具がまだまだありますが、それは必要になったときに調べれば（あるいは社内AIチャットに聞けば）十分です。

_出典: [pandas 公式ドキュメント「pandas.read_csv」](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html)（2026年8月取得）_

## 標準の csv とどちらを使えばいいのか

「pandas がこんなに楽なら、前のレッスンの `csv` は何だったのか」と思うかもしれません。答えは、**どちらを使ってもよい**です。

| | 標準の csv / json | pandas |
| --- | --- | --- |
| 導入 | 不要（同梱） | `uv add` が要る |
| 向き | 1行ずつ読んで、条件や変換を細かく書く | 表をまるごと読んで、集計を短く書く |
| 中身の形 | 辞書のリスト（文法基礎コースの道具で加工） | DataFrame（pandas の道具で加工） |

1行ずつの加工ロジックが主役なら csv、集計が主役なら pandas——使い分けはこの程度の緩さで十分ですし、この先のハンズオン（ツール開発実践シリーズ（準備中））でもどちらを使っても構いません。**csv で学んだ「読む → 加工する → 書き出す」の骨格は、道具が変わっても同じ**です。
