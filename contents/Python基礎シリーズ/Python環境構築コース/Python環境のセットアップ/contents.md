# Python環境のセットアップ

## 学習目標

前のコースで地図を手に入れました。ここからは装備を整える番です。このレッスンでは、Python を動かすための道具 **uv（ユーブイ）** を導入します。作業は数分で、**申請も承認待ちもありません**——はじめにシリーズで入れた Chocolatey から、コマンド1つで入ります。

終わる頃には、`uv --version` が答えを返す状態になり、なぜ「Python 本体」ではなく uv を先に入れるのかが分かっています。

## なぜ uv か

「社内は Anaconda では？」と思った人もいるはずです——その答えはこの節の最後にあります。まずは uv が何者かから。

プログラミング学習では、文法より先に**環境構築**でつまずいた経験のある人が多いはずです。Python 本体のバージョン、ライブラリの追加、プロジェクトごとの使い分け——管理するものが多く、手作業でやると壊れやすいためです。

そこで登場するのが uv です。uv は Python の**調達係**だと思ってください。Python 本体も、あとで使うライブラリも、自分で探して入れる代わりに調達係に頼みます。頼んだものの手配と管理を、uv が一手に引き受けてくれます。

## uv を入れる

uv は Chocolatey から入ります。**IT Service Portal への申請は不要**です——Chocolatey のセットアップのときに済ませた申請が、ここで効いてきます。

ターミナルで次を実行します。Chocolatey のセットアップの確認で開いた **PowerShell と同じもの**で構いません（VSCode の中のターミナルでも同じことができます）。

```powershell
choco install uv
```

進行状況が何行か流れます。出力の中に次の行があれば成功です（前後に他の行も出ます）。

```text
The install of uv was successful.
```

> [!TIP]
> 途中で `[Y]es` のような英語の確認を求められたら、`Y` を入力して Enter で先へ進めます。また、権限のエラー（Access Denied など）で止まったときは、ターミナルを**「管理者として実行」で開き直して**から再実行してください。`choco` というコマンド自体が見つからないと言われた場合は、はじめにシリーズの「Chocolatey のセットアップ」の確認手順に戻ってください。

続けて、入ったことを確かめます。

```powershell
uv --version
```

```text
uv 0.11.6 (65950801c 2026-04-09 x86_64-pc-windows-msvc)
```

バージョンの数字や括弧の中身が上と違っていても問題ありません。**「uv」で始まる1行が返ってくること**が確認のすべてです。

> [!TIP]
> `uv` というコマンドが見つからないと言われたら、**ターミナルをいったん閉じて開き直して**からもう一度試してください。インストール直後は、開きっぱなしのターミナルに新しいコマンドがまだ知らされていないことがあります。

## Python 本体はまだ入れなくていいのか

ここで気になった人がいるかもしれません。「Python のレッスンなのに、Python 自体はいつ入れるのか？」

答えは、**このトレーニングでは自分では入れません**（正確には自分で入れるコマンドもありますが、使う場面はありません）。uv は、スクリプトを動かそうとしたときに必要な Python 本体を自動で用意してくれます。調達係を雇ったので、個別の買い出しは任せてよいのです。実際にその場面は次のレッスンで体験します——初めてスクリプトを実行する瞬間に、uv が Python を手配する様子が見えます。

_出典: [uv - Astral Docs「Running scripts」](https://docs.astral.sh/uv/guides/scripts/)（2026年8月取得）_

## やってみる

- やること: 本文を読みながら `choco install uv` をまだ実行していなければ実行し、続けて `uv --version` でバージョンの行が返ることを確認する。**本文ですでに実行済みの人は `uv --version` の確認だけで完了**です
- 前提: Chocolatey が導入済み（はじめにシリーズの開発環境準備コース）
- 考えなくてよいこと: バージョンの数字の意味。表示さえ返れば先へ進めます

<details>
<summary>解答例</summary>

`uv 0.11.6 (...)` のような1行が表示されれば成功です。

</details>

## まとめ

このレッスンの持ち帰りは3つです。

1. uv は Python の**調達係**——本体もライブラリも、手配は uv に頼む
2. 導入は Chocolatey から **`choco install uv` の1コマンド**。申請は不要
3. Python 本体は自分では入れない。**必要になったとき uv が自動で用意する**

装備が1つ増えました。次のレッスンでは、いよいよ最初のスクリプトを動かします。

## 確認問題

1. uv の役割を、「調達係」という言葉を使わずに自分の言葉で1文にしてみてください。
2. このレッスンで Python 本体をインストールしなかったのはなぜでしょうか。
