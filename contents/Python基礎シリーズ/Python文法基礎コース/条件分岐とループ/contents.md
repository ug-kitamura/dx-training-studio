# 条件分岐とループ

## 学習目標

前のレッスンで、値を箱（変数）に入れて扱えるようになりました。このレッスンでは、手順書に**分かれ道**と**繰り返し**を書けるようにします。「在庫が足りないものだけ知らせる」「10個のファイルに同じ処理を10回やる」——業務の自動化はほぼ必ずこの2つでできています。

あわせて、Python 特有の**インデント（字下げ）のルール**をここで押さえます。見た目の飾りではなく文法そのものなので、最初に正体を知っておくと後のレッスンが全部楽になります。

## 分かれ道を書く——if

このレッスンも、`python-practice` にファイルを1枚作って（`bunki.py` など）、本文のコードを書き換えては `uv run` で動かしながら読み進めてください。

条件によって処理を変えるには `if` を使います。

```python
count = 12
if count > 10:
    print("多め")
else:
    print("ふつう")
```

```text
多め
```

読み方はほぼ英語のとおりです。「もし `count` が 10 より大きいなら『多め』、そうでなければ（else）『ふつう』」。`count` は 12 なので、実行されるのは上の行だけです。

形のルールは2つだけです。

1. 条件の行の末尾に **`:`（コロン）** を付ける
2. 条件が成り立ったときにやる行を、**スペース4つ下げて**書く（厳密には幅が揃ってさえいれば動きますが、4つが標準です。いまはこれで十分）

この「下げ」がインデントです。試しにインデントを消して実行すると、Python は動くことを拒否します。

```python
count = 12
if count > 10:
print("多め")
```

```text
IndentationError: expected an indented block after 'if' statement on line 2
```

（表示は最後の行だけ抜き出しています。行番号は自分のファイルでの位置になります。）意味は「2行目の if 文のあとに、字下げされた中身があるはずです」。多くの言語ではインデントは読みやすさのための飾りですが、**Python では「どこからどこまでが if の中身か」をインデントで判定します**。つまり文法の一部です。エディタが自動で下げてくれることが多いので手で数える場面は少ないですが、「ズレると動かない」ことだけ覚えておいてください。

分かれ道が3本以上あるときは `elif`（else if の略）でつなぎます。

```python
count = 12
if count > 20:
    print("かなり多め")
elif count > 10:
    print("多め")
else:
    print("ふつう")
```

```text
多め
```

出力は「多め」の1行だけです。12 は `> 20` には当てはまらず、次の `> 10` で成り立ったのでそこが実行されました。**上から順に判定され、最初に成り立った1本だけ**が実行されます——`> 10` より下は見られもしません。

## 繰り返す——for

同じ処理を回数分やるには `for` を使います。

```python
for i in range(1, 6):
    print(i)
```

```text
1
2
3
4
5
```

`range(1, 6)` は「1 から 5 まで」の数の並びです。**終わりの 6 は含まれない**——ここは初見の全員が引っかかる仕様なので、「range(a, b) は a から b の1つ手前まで」と唱えて覚えてください。`i` は普通の変数で、**箱の中身が1周ごとに入れ替わる**イメージです。

`for` の中身もインデントで示します。「インデントされている行まで」が繰り返される範囲です。境界を出力で確かめてみます。

```python
for i in range(1, 4):
    print(i)
    print("処理中")
print("終わり")
```

```text
1
処理中
2
処理中
3
処理中
終わり
```

インデントされた2行は3回ずつ、**インデントの無い「終わり」は1回だけ**——つまりループの外です。「ループに入れたつもりの行が外にあった」はインデント事故の定番なので、迷ったらこの形を思い出してください。

なお、他の言語にある `while`（回数の決まらない繰り返し）は Python にもありますが、このシリーズでは扱いません。業務スクリプトの繰り返しは for でほぼ足ります。

## 組み合わせる——ループの中の分かれ道

`for` と `if` は入れ子にできます。1〜10 のうち偶数だけを表示してみます。

```python
for i in range(1, 11):
    if i % 2 == 0:
        print(i)
```

```text
2
4
6
8
10
```

新顔が2つあります。**`%` は割り算の余り**を返す演算子で、`i % 2 == 0` は「2 で割った余りが 0、つまり偶数」という条件です。そして**比較の `==` は `=` を2つ**重ねます。1つの `=` は「箱に入れる」でしたから、「比較したいのに代入してしまった」は定番の書き間違いです。エラーや変な動きに出会ったら、まず `=` の数を数えてください。

インデントが2段になっていることにも注目してください。`if` の行は for の中なので1段、`print` は if の中なので2段。**インデントの深さが「どの命令の中にいるか」をそのまま表しています。**

```text
for …:            ← 繰り返しの入口
    if …:         ← 1周ごとの分かれ道（for の中: 1段下げ）
        print(…)  ← 条件が成り立ったときだけ（if の中: 2段下げ）
```

## まとめ

このレッスンの骨は3つです。

1. 分かれ道は **`if` / `elif` / `else`**。条件行の末尾に `:`、中身はインデント
2. 繰り返しは **`for i in range(a, b)`**。b は含まれない
3. **インデントは文法**。深さが「どの命令の中にいるか」を表す
