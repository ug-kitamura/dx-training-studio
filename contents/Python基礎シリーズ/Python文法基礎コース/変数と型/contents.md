# 変数と型

## 学習目標

ここからは文法基礎コース。手順書に書ける命令を増やしていく段です。最初のレッスンでは、あらゆるスクリプトの土台になる**変数**と**型**を扱います。

終わる頃には、値に名前を付けて使い回せるようになり、「文字と数を混ぜたらエラーになった」という初学者が必ず一度は踏む場面を、自力で切り抜けられるようになっています。

## 変数は「名札付きの箱」

このレッスンからは、コードを**手元で動かしながら**読み進めてください。`python-practice` の中に `hensu.py` のようなファイルを1枚作り、本文のコードを書き換えては `uv run hensu.py` で実行する——前のコースで覚えた一周を、そのまま繰り返す形です。以降のコードはすべて同じやり方で試せます。

変数とは、**値を入れておく名札付きの箱**です。箱に入れておけば、あとから名札で呼び出せます。

```python
name = "佐藤"
count = 12
print(name)
print(count)
```

```text
佐藤
12
```

`=` は「等しい」ではなく、**右の値を左の名札の箱に入れる**という命令です。ここは数学と意味が違うので、最初に読み替えを済ませてしまいましょう。

では、`print("佐藤")` と直接書くのと何が違うのか。箱の意味は**使い回し**にあります。

```python
name = "佐藤"
print(name + "さんが担当します")
print(name + "さんに連絡してください")
```

担当が鈴木さんに替わったら、直すのは**1行目だけ**です。値を直接書き散らすと、替わるたびに全部の行を探して直すことになります。

変数名は自分で決めます。`name` や `count` のように**中身が想像できる英単語**を付けるのが慣例です。`a` や `x` でも動きますが、1週間後の自分が読めなくなります。

## 中身には種類がある——「型」

箱の中身には**種類**があります。これを**型**と呼びます。まずは4つだけ覚えれば十分です。

| 型 | 何の値か | 例 |
| --- | --- | --- |
| `str`（文字列） | 文字の並び。**引用符で囲む** | `"佐藤"`, `"hello"` |
| `int`（整数） | 小数点のない数 | `12`, `-3` |
| `float`（小数） | 小数点のある数 | `0.75`, `2.5` |
| `bool`（真偽値） | はい／いいえ の2択 | `True`, `False` |

`True` / `False` は**先頭が大文字**です。他の言語の感覚で `true` と書くと「そんな名前は知らない」というエラー（`NameError`）になります。また、bool は次のレッスン（条件分岐）で主役になるので、いまは名前と `True` / `False` の2つだけ知っていれば十分です。

値がどの型かは、`type()` で確かめられます。

```python
print(type("佐藤"))
print(type(12))
print(type(0.75))
print(type(True))
```

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

`<class 'str'>` という表示の読み方は「これは str 型です」で十分です。`class` という単語の意味は、いまは気にしなくて構いません。

ここで大事な区別が1つ。**`12` と `"12"` は別ものです。** 前者は計算できる整数、後者は「1 と 2 という文字が並んだだけ」の文字列です。見た目がそっくりなぶん、次の節のエラーの主犯になります。

## 型が違うと混ぜられない

では、文字列と整数を `+` でつなぐとどうなるか。試してみます。

```python
print("1" + 1)
```

```text
TypeError: can only concatenate str (not "int") to str
```

エラーになりました。前のレッスンで覚えたとおり**最後の行**を読んでみましょう（表示は要点の最終行だけ抜き出しています。手元では `Traceback` から始まる数行が出ますが、読む場所は同じです）。意味は「str 同士しか連結できません。int はつなげません」。**Python は型の違う値を勝手に混ぜない**のです。不便に見えますが、「1 + 1 = 2 なのか、文字として 11 なのか」を勝手に決められるほうが事故になります。ここで止まってくれるのは、むしろ安全装置です。

混ぜたいときは、**型を変換してから**混ぜます。

```python
print(int("1") + 1)
print("担当は " + str(12) + " 件")
```

```text
2
担当は 12 件
```

`int()` は文字列を整数に、`str()` は値を文字列に変換します。「**足し算したいなら int() に、文につなぎたいなら str() に**」——この対応だけ持ち帰れば、このエラーはもう怖くありません。小数の文字列なら `float()` で、仕組みは同じです。

## 表示を整える——f-string

変数を文に混ぜて表示したい場面は多いので、便利な書き方を1つ覚えます。引用符の前に `f` を付けると、`{}` の中に変数を直接埋め込めます。

```python
name = "佐藤"
count = 12
print(f"{name}さんの担当は{count}件です")
```

```text
佐藤さんの担当は12件です
```

`str()` での変換も `+` でのつなぎも不要になります。この書き方（**f-string** と呼びます）は、このシリーズの以降のレッスンでも表示の場面でずっと使っていきます。

## まとめ

このレッスンの骨は3つです。

1. 変数は**名札付きの箱**。`=` は「箱に入れる」
2. 型はまず4つ——**str / int / float / bool**。`12` と `"12"` は別もの
3. 型が違うと混ぜられない。**足し算は `int()`、文につなぐなら `str()` か f-string**

## 確認問題

1. `"3" + "4"` の結果は `"34"`（文字列）になります。なぜ `7` にならないのか、「型」という言葉を使って説明してみてください。
