# リストと辞書

## 学習目標

分かれ道と繰り返しを覚えたので、今度は**データをまとめて持つ器**を手に入れます。文法基礎コースの仕上げのレッスンです。

メンバー10人の名前を扱うのに、変数を10個作るわけにはいきません。このレッスンでは、たくさんの値を1つの変数で持つ**リスト**と**辞書**を使えるようにします。この2つは、業務データを扱うスクリプトのほぼすべてに登場します。

## 番号で引く棚——リスト

このレッスンも、`python-practice` にファイルを1枚作って（`tana.py` など）、本文のコードを動かしながら読み進めてください。

前に学んだ変数は「名札付きの箱」でした。リストは、**箱を順番に並べた棚**です。

```python
members = ["佐藤", "鈴木", "高橋"]
print(members[0])
```

```text
佐藤
```

`[]` の中にカンマ区切りで値を並べると、リストになります。取り出すときは `members[0]` のように**棚の番号**で指定します。ここで大事な仕様が1つ——**番号は 0 から始まります**。先頭が 0、2番目が 1。前のレッスンの `range(1, 6)` が「6 を含まない」のと並ぶ、Python の数え方のクセです。

棚に無い番号を指定するとどうなるかも、わざと踏んでおきましょう。

```python
print(members[3])
```

```text
IndexError: list index out of range
```

（表示は最後の行だけ抜き出しています。）エラー名ごと「**棚の範囲の外**」と覚えてしまってください。

棚に並んでいる個数は `len(members)`（この例では `3`）で数えられます。棚への追加は `append` です。

```python
members.append("田中")
print(members)
```

```text
['佐藤', '鈴木', '高橋', '田中']
```

書き方に新顔が2つ紛れています。まず、棚に備え付けの操作は `members.append(...)` のように**ドットでつないで**呼びます。`len()` のような関数形との使い分けの理由は、いまは気にしなくて大丈夫です。もう1つ、出力の引用符が `'佐藤'` とシングルクォートになっていますが、Python では `"` と `'` は**どちらも同じ文字列の引用符**です。表示の流儀が違うだけで、意味は変わりません。

そしてリストは、前のレッスンの `for` とセットで真価を出します。**棚の端から端まで、1つずつ取り出して同じ処理をする**——これが業務スクリプトの最頻出パターンです。変数を10個作る方式ではこれができません——11人目が来るたび、コードを書き足すことになります。

```python
for member in members:
    print(f"{member}さん、お疲れさまです")
```

```text
佐藤さん、お疲れさまです
鈴木さん、お疲れさまです
高橋さん、お疲れさまです
田中さん、お疲れさまです
```

`range` のときと形は同じで、数の並びの代わりにリストを渡すだけです。1周ごとに `member` の箱の中身が入れ替わり、さっき `append` した田中さんまで、4人全員が処理されています。

## 名札で引く棚——辞書

リストが「番号で引く棚」なら、辞書は**名札で引く棚**です。1件のデータの中身に名前を付けて持ちます。

<!--
リストと辞書の左右比較図。左のカードは「リスト＝番号で引く棚」で、0・1・2 の番号札が付いた棚に "佐藤" "鈴木" "高橋" が並ぶ。右のカードは「辞書＝名札で引く棚」で、"name"・"stock" の名札が付いた棚に "モニター"・4 が入っている。左右のカードの要素の位置をそろえ、下にそれぞれ members[0] / item["name"] という取り出し方のコードラベルを添える
-->
![リストは番号で引く棚、辞書は名札で引く棚という左右比較図](images/list-vs-dict-shelves.png)

図の対比がすべてです——**左（リスト）は番号で、右（辞書）は名札で取り出す**。同じ「棚」でも引き方が違います。図の下のコードラベルは、このすぐ後で説明します。

```python
item = {"name": "モニター", "stock": 4}
print(item["name"])
print(item["stock"])
```

```text
モニター
4
```

`{}` の中に `名札: 値` のペアを並べます。名札のことを**キー**、対になる中身を**値**と呼びます。取り出すときは `item["name"]` のように名札で指定します。「在庫数は何番目だっけ」と数えなくてよいのが辞書の強みです。

無い名札を引くと `KeyError: '名札'` で止まります。エラーには**打った名札がそのまま出る**ので、打ち間違い（`"name"` を `"nmae"` など）にすぐ気づけます。リストの IndexError と対で覚えてください。

どちらを使うかの目安はシンプルです。

| 器 | 向いているもの | 例 |
| --- | --- | --- |
| リスト | **同じ種類**の値の並び。順番に処理したい | メンバー名の一覧、ファイル名の一覧 |
| 辞書 | **1件のデータの中身**。項目に名前がある | 備品1件の「品名・在庫数」 |

## 棚を組み合わせる——辞書のリスト

実務のデータは、この2つの組み合わせで表せます。備品の一覧なら、「**辞書（1件分）を、リスト（並び）に入れる**」形です。なお、次のコードの f-string の中では、外側の `"` と重ならないように名札を `item['name']` と**シングルクォート**で書いています（どちらも同じ引用符でしたね）。

```python
items = [
    {"name": "モニター", "stock": 4},
    {"name": "キーボード", "stock": 12},
]
for item in items:
    print(f"{item['name']}: 残り{item['stock']}個")
```

```text
モニター: 残り4個
キーボード: 残り12個
```

`for` で1件ずつ取り出し、名札で中身を読む。**表データの1行が辞書、表全体がリスト**——この対応は、中級コースで CSV ファイルを読むときにそのまま再登場します。ここで形に見覚えを作っておいてください。

## まとめ

このレッスンの骨は3つです。

1. リストは**番号で引く棚**。番号は 0 始まり、`for` で1つずつ処理できる
2. 辞書は**名札（キー）で引く棚**。1件のデータの中身に名前を付ける
3. 実務データは「**辞書のリスト**」の形が定番。表の1行=辞書、表全体=リスト

これで文法基礎コースはクリアです。変数・分岐・繰り返し・リスト・辞書——スクリプトの基本部品がそろいました。次の中級コースでは、この部品を組み合わせて「読む → 加工する → 書き出す」の形に組み上げていきます。
