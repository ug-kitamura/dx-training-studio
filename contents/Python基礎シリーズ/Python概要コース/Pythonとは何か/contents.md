# Pythonとは何か

## 学習目標

新しいシリーズの始まりです。Python基礎シリーズは、このレッスンを含めて**全9レッスン**。環境づくり、基本文法、ファイルの読み書き、既製ライブラリの使い方へと進みます。修了すると、**業務データのファイルを読んで、加工して、別の形式で書き出すスクリプト**を自分の手で書けるようになります——繰り返しの手作業を任せられる、自分の武器が1つ増えるということです（「スクリプト」という言葉は、このレッスンの後半で説明します）。

その最初のクエストがこのレッスンです。コードはまだ書きません。先に「Python は何が得意で、自分の業務のどこで使えるのか」という地図を手に入れます。ゴールは、**自分の業務で自動化したい作業を1つ、言葉にできる**ことです。

## Python はどんな言語か

プログラミング言語はたくさんあるのに、なぜこのトレーニングは Python なのか——まずそこからです。理由は3つあります。

| 理由 | どういうことか |
| --- | --- |
| **読みやすい** | 文法の飾りが少なく、書いた本人以外にも意図が伝わりやすい |
| **短く書ける** | 同じ処理を他の言語より少ない行数で書けることが多い |
| **既製品の道具が豊富** | 表の集計・ファイル操作・グラフ描画など、よくある仕事には出来合いの部品（**ライブラリ**と呼びます）が揃っていて、自分でゼロから書かずに済む |

たとえば、名前のリストに順番にあいさつするコードはこう書けます。

```python
names = ["佐藤", "鈴木", "高橋"]
for name in names:
    print(name + "さん、こんにちは")
```

これまでに触った言語の感覚で、初見でもだいたい何をしているか読めるのではないでしょうか。**いまは細部が読めなくて大丈夫です**——この書き方は文法基礎コースで一つずつ扱います。ここでは「構えずに読める言語だ」という感触だけ持ってください。

選ばれた理由は上の3つですが、学ぶうえで嬉しい性格がもう1つあります。Python は**書いたらすぐ実行できる**タイプの言語です（厳密には内部で変換の段階がありますが、最初の理解は「保存して実行、すぐ結果が見える」で十分です）。試しては直すのを短い間隔で繰り返せるので、初学者の練習にも、業務の小さなツールづくりにも向いています。

まず上の絵で「4つの場面がある」ことだけつかんでください。それぞれの具体例は、下の表で確かめられます。

| 場面 | 例 |
| --- | --- |
| 表データの集計 | 複数の CSV ファイルを読み込んで、1つの集計表にまとめる |
| ファイル整理 | フォルダに溜まった数百のファイルを、名前の規則で仕分け・リネームする |

共通するのは、**やり方が決まっていて、人が繰り返している作業**だということです。逆に、判断や交渉のように毎回やり方が変わる仕事は Python の出番ではありません。「決まった手順の繰り返しかどうか」が、自動化できるかどうかの最初の見分け方です。

## このシリーズのゴール

ここまで「スクリプト」という言葉を説明なしに使ってきました。スクリプトとは、**やってほしい作業を書いた手順書のファイル**のことです。Python に渡すと、書いたとおりに実行してくれます。このシリーズの終わりに書けるようになるのは、次の形のスクリプトです。

```text
入力ファイル（CSV など）──→ あなたのスクリプト ──→ 出力（JSON・集計結果）
      読む                     加工する                  書き出す
```

上の4つの場面の多くは、この「読む → 加工する → 書き出す」の変形です。きれいに3つ揃わないものもありますが（ファイル整理には「書き出す」がない、など）、骨格は同じです。この形を一度自分の手で作れると、応用が一気に利くようになります。

そこまでの残りの道のりは3コースです。まず**環境構築コース**で Python を動かせる状態を作り、**文法基礎コース**で部品の使い方を覚え、**中級コース**でこの形のスクリプトを組み立てます。1レッスンは10〜15分なので、少しずつ進めて大丈夫です。

## やってみる

自分の業務の中で、「自動化したい」と思う作業を1つ書き出してください。メモアプリでも紙でも構いません。

- やること: 作業の名前と、いま何が面倒かを1〜2行で書く
- 前提: 「決まった手順の繰り返し」に当てはまりそうなものを選ぶ
- 考えなくてよいこと: どうやって実現するか、自分に作れるかどうか

## まとめ

持ち帰るのはこの3つです。

1. Python は**読みやすく、短く書けて、既製品の道具（ライブラリ）が豊富**な言語
2. 得意なのは**やり方が決まっていて、人が繰り返している作業**
3. このシリーズのゴールは「**読む → 加工する → 書き出す**」のスクリプトを自分で書けること
