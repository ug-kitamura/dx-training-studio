# 応用課題に挑む（2日目）

## 学習目標

ハンズオン2日目、このトレーニングの最終クエストです。今日の60分で、Part 2 の実装を仕上げ、相方とのレビューを通してマージし、**自分のコードを自分の言葉で2分間発表**します。それが終わったとき、あなたは DX トレーニングの全シリーズを走りきったことになります。

先に言い切っておきます。**Part 2 が解けきっていなくても、今日は成立します。** 発表は「できた人の披露会」ではなく、全員が自分の工夫と詰まりを持ち寄る場です。

## 今日の時間割

```text
00-05  進捗確認（運営が挙手で聞くだけ。詰まっていてもそのまま申告して大丈夫）
05-30  Part 2 実装（25分）
30-38  PR 作成 → 相方がレビュー → 承認 → マージ
38-54  発表  各自2分 × 8人
54-60  まとめ
```

## 実装を仕上げる

25分で、書けるところまで書きます。ブランチは手元の状態に合わせてください。

- 間の数日で**既に別ルート（ブランチ）で進めている人**は、その続きで
- **main に直接コミットしてしまった人**は、いまの main から新しくブランチを切ればそのまま進められます（この場合 PR に載せる差分が作れないので、運営に声をかけてください）
- **今日から書き始める人**は、1日目と同じく別ルートを切ってから

- この3〜4日で完成した人は、動作を見直して仕上げます。4週分の出力を眺めて、前の週と同じペアが同じ組にいないか目で確かめておくと、発表で見せやすくなります
- 途中の人は、**動くところまでを区切りにして**仕上げます。全部できていなくても、たとえば「4週分の出力までは動く」なら、それが今日の成果です
- 詰まっている人は、**どこで詰まったか・何を試したか**を言葉にしておいてください。それはそのまま発表の材料になり、聞く側にとっては自分が踏まなかった落とし穴の共有になります

困ったら1日目と同じです。社内AIチャットに聞く、相方に相談する、運営に声をかける——全部使ってかまいません。

## PR → レビュー → マージ

流れは1日目とまったく同じです（手順は1日目のページの表を見返してください）。違いは2つだけ。

- **途中でも PR を出してよい。** できたところまでを合流させます。main に「今日までの成果」が残ることが大事です
- レビューの質問は、**Part 2 の工夫どころ**に向けてください。「この条件はどうやって満たしたのですか？」——1日目より聞きたいことが自然に浮かぶはずです。答える練習が、直後の発表のウォーミングアップになります

出せる差分が無い人は、この時間は**相方の PR のレビューに回ってください**。質問するのは、PR を出していなくてもできます。マージできた人は、1日目と同じく main に戻して動かしておきましょう——発表で見せるのはその画面です。

## 発表する——2分で3点

全員が2分ずつ話します。順番と見せ方（画面の映し方）は当日運営が案内します。話すことは3点だけです。

| 順 | 話すこと | 目安 |
|---|---|---|
| 1 | **動くところを見せる**（実行して、出力の JSON を見せる） | 30秒 |
| 2 | **工夫したところを1つ**（どう分けたか、なぜそう書いたか） | 1分 |
| 3 | **詰まったところを1つ**（どこで、何を試したか） | 30秒 |

途中までの人は、型を少し変えます。

| 順 | 話すこと | 目安 |
|---|---|---|
| 1 | できたところまでを見せる（動く範囲の実行でよい） | 30秒 |
| 2 | どこで詰まったか、何を試したか | 1分 |
| 3 | いま思っている「次に試すこと」 | 30秒 |

Part 2 が動いていなければ、**1日目に完成させた Part 1 の実行を見せれば十分**です。あれも今日のあなたのツールです。

どちらの型でも、**自分の書いたコードを自分の言葉で説明する**ことは同じです。AI に聞きながら書いたとしても、選んで、組み立てて、動かしたのはあなたです。うまく話そうとしなくてかまいません——**詰まった箇所の共有そのものが、他の参加者の学びになります**。

## 解き方は1つではない

8人の発表を聞くと、同じ課題に対して**解き方がばらばら**なことに気づくはずです。それがこの発表のいちばんの価値です。

数学的に組み立てた解も、素朴に組んだ解も、条件を満たして動けばどちらも正解です。「その手があったか」と思った分け方は、遠慮なく持ち帰ってください。仲間のコードから盗むのは、共有保管庫の世界ではまっとうな学び方です。
