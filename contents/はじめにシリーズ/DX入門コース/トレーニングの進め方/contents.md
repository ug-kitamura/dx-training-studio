# トレーニングの進め方

## 学習目標

テクノロジーの進化は速く、常に学び続ける必要があります。だからこそ、このトレーニングで一番大事にしてほしいのは、**教わるのではなく、自ら学ぶ姿勢**です。私たちは、そうやって学ぼうとする人を全力でお手伝いします。

このレッスンでは、トレーニング全体のゴールと、学びの地図「曼陀羅」の見方を手に入れます。読み終わる頃には、自分がどの順番で進むかを自分で決められるようになっています。

## ゴールはひとつ——動くツールを自分の手で完成させる

本トレーニングは、このキックオフ＋3週間の自己学習＋最後に1時間2回のハンズオンでできています。そのうえで、メインクエストを先に言い切ります。**最後のハンズオンで、業務を助ける小さなツールを1つ、必ず動くところまで自分の手で完成させる**——これがゴールです。何を作るかは、いま考えなくて大丈夫です。題材は運営が用意していて、ハンズオン当日に発表されます。

そのために、3週間の自己学習期間で武器を揃えていきます。AI への聞き方、Git と GitHub でのコードの残し方・見せ方、Python でのスクリプトの書き方。どれもハンズオン当日に実際に使うものだけを選んであります。

修了したとき手元に残るのは、自分で作った動くツールと、「調べて、聞いて、作り切った」という経験です。ひとつ約束してほしいことがあります。**分からないことは、まず自分で調べ、AI に聞いて前に進むこと。** 運営はあなたの代わりにツールを作りません——自分で調べて前に進む力こそ、このトレーニングで身につけてほしい仕事の進め方だからです。

## 冒険の地図——曼陀羅の見方

このトレーニングには「曼陀羅」と呼ぶ地図があります。RPG の冒険の地図と同じで、**クエスト（コース）を終えると、矢印の先にある次のエリアが解放されます**。全体はこういう形です。

```text
             はじめにシリーズ
   ┌──────────────────────────────────────┐
   │  DX入門コース ★イマココ               │
   │     │      └───▶ 開発環境準備コース    │
   │     │              │         │       │
   └─────┼──────────────┼─────────┼───────┘
         ▼              ▼         ▼
      AI基礎        Git基礎     Python基礎
     シリーズ       シリーズ      シリーズ
         │              ▼         │
         │          GitHub基礎     │
         │           シリーズ      │
         └─────────┬────┴─────────┘
                   ▼
      ツール開発実践シリーズ（ハンズオン）
```

> **社内画像**: 曼陀羅の全体像のスクリーンショット。受講者が実際に見る画面（学習サイトの曼陀羅ページ、またはキックオフ当日に投影する資料の該当ページ）を、6シリーズすべてと矢印が1枚に収まる状態で撮る。個人名・進捗情報が写る場合はマスクする

図の見どころは**矢印の出どころ**だけです。読み方は2つだけ覚えてください。

1. **矢印の手前を終えると、先が解放される。** AI基礎シリーズへの矢印は DX入門コース（いまここ）から、Git基礎・Python基礎シリーズへの矢印は開発環境準備コースから出ています。つまり Git基礎シリーズに入るには、開発環境準備コースまで終えている必要があります
2. **道が分かれているところは、どちらから進んでもよい。** 進む順番は地図が決めるのではなく、自分で選びます

細かい配置は覚えなくて大丈夫です。「解放しながら進む地図がある」と分かれば十分です。

## 自分の進む順番を決める

地図を見ると、はじめにシリーズの先は3方向に分かれています。AI基礎シリーズはすぐに進めます。Git基礎シリーズと Python基礎シリーズは、開発環境準備コース（このシリーズの残り2レッスン）を終えると解放されます。

その先はどう進んでも構いません。Git を GitHub まで一気に進めてから Python に入る人もいれば、Python を先に済ませる人もいます。**すべてのシリーズを終えると、最後のツール開発実践シリーズ（ハンズオン）への道が開きます。**

途中、環境構築や権限取得のための申請が必要になる場面が何度かあります。申請を待っている間は進められるところを各自進めておいてください。

## 困ったときの拠り所

一人で進めていると、必ずどこかで詰まります。そのために Teams チャンネル「**DX Tools Training**」を用意しました。受講者は全員、運営から招待されます。

- 質問はいつでも歓迎です。ただし、答えそのものではなく**ヒントだけ**をお返しすることがあります——自分で考える余地は、あなたの武器になるからです
- 回答するのは運営と数名のボランティアです。すぐに返事ができないこともある点はご了承ください

順番としては、まず自分で調べる・AI に聞く、それでも動けなくなったらチャンネルへ。キックオフで案内した各種申請や、環境のトラブルのように自分では解決しようがないことは、遠慮なくすぐ聞いてください。

なお、この教材は受講期間中にも更新されます。大きな変更があったときは同じチャンネルでお知らせしますので、見かけたら確認してください。何がどう変わったかは[変更履歴](../../changelog)のページに載せています。いま読んでいるページが最新かどうかは、サイドバーの一番上にある更新日で確かめられます。

## まとめ

持ち帰るのはこの3つです。

1. ゴールは**動くツールを1つ、自分の手で完成させる**こと
2. 曼陀羅は**解放しながら進む地図**。進む順番は自分で選ぶ
3. 詰まったら、調べて・AI に聞いて・それでも駄目なら **DX Tools Training** チャンネルへ

いま解放されているのは、開発環境準備コースと AI基礎シリーズ。さっき書き出した順番で、最初のクエストへ。冒険の始まりです。
