# VSCodeのインストールと初期設定

## 学習目標

環境準備の仕上げです。このレッスンでは **VSCode（Visual Studio Code）** を導入します。VSCode は拡張性の高いコードエディタです。この先、Git の操作も Python のコード書きもすべて引き受けるメインの道具です。

ゴールは「フォルダを開いて、ファイルを1つ作って編集できる」こと。それ以上の機能はまだ触りません。

## 入れ方は2つある。案内するのは部門の正規手順

社内には VSCode の導入経路が2つあり、どちらにするかで迷う人が多いところです。結論から言うと、**このトレーニングでは①だけを案内します**。

| 経路                                                | 位置づけ                                                 |
| --------------------------------------------------- | -------------------------------------------------------- |
| ① Chocolatey から**部門向けカスタマイズ版**を入れる | **部門の正規手順**。本トレーニングではこちらを採用する   |
| ② 社内システムから VSCode を直接入れる              | 会社の正規手順。動きはするが本トレーニングでは案内しない |

①を選ぶ理由は2つです。部門標準の設定が最初から揃っていること、そして全員が同じ状態になるので、この先「自分の画面だけ違う」で詰まらないこと。すでに②で入れている人は、そのままでも進められますが、画面や設定が本文と一部異なる場合があります。

## Chocolatey から VSCode を入れる

前のレッスンで Chocolatey が入っていれば、ここはワンクリックです。

1. スタートメニューで「**Chocolatey GUI**」を検索して開く
2. 一覧から部門向けカスタマイズ版の **VSCode** を探す
3. 「**Install**」ボタンをクリックする

コマンド入力は不要で、申請も要りません（申請が必要だったのは Chocolatey 本体だけです）。

> **社内画像**: Chocolatey GUI で部門向けカスタマイズ版 VSCode を入れる一連の画面。差し込みは「画面が変わるごとに1枚」を目安に、上の手順1〜3の範囲を対象とする。最低限、一覧で部門向けカスタマイズ版 VSCode の表示名が読める画面と、「Install」ボタンが見える画面の2枚。GUI の起動方法やパッケージの表示名が本文と異なっていたら、本文側をあわせて直す。PC の管理番号・ユーザー名が写る場合はマスクする

インストールが終わったら、スタートメニューから VSCode を起動してください。初回起動で「ようこそ」のようなタブが開いていたら、タブの×で閉じてかまいません。

## 最初に見る場所は3つだけ

初めて開くと、見慣れないボタンが並んでいて戸惑うかもしれません。機能は確かに多いのですが、**いま見る場所は3つだけ**です。ほかは全部、当面無視してかまいません。

> [!NOTE]
> VSCode は「拡張機能」を追加して機能を増やせます（例: Git の履歴を図で見られる Git Graph——これは許可済みです）。ただし**社内で入れられる拡張機能は許可されたものに限られます**。いまは何も入れなくて大丈夫です。必要になったレッスンでその都度案内します。

## フォルダを開いて、ファイルを作る

VSCode は「ファイルを1つずつ開く」より「**フォルダごと開く**」道具です。この先の Git も Python も、フォルダ単位で作業します。流れを一度通しておきましょう。

1. デスクトップなど分かりやすい場所に、練習用フォルダ `dx-practice` を作る
2. VSCode の「ファイル（File）」メニュー →「フォルダーを開く（Open Folder）」で `dx-practice` を選ぶ（「このフォルダー内のファイルの作成者を信頼しますか？」と聞かれたら「はい」でかまいません——自分で作ったフォルダです）
3. VSCode 左側のエクスプローラーで、フォルダ名の右にある「新しいファイル」アイコンをクリックし、`memo.txt` と入力して Enter（アイコンはマウスをフォルダ名の行に載せると現れます）
4. エディタで好きな1行を書き、`Ctrl+S` で保存する

タブの見出しの●（未保存の印）が消えれば、保存できています。

## やってみる

上の手順どおり、練習用フォルダ `dx-practice` を開いて、ファイルを1つ作ってください。前の節で手を動かしながら読んだ人は、●が消えている（保存済み）ことの確認だけで OK です。

- 前提: 前のレッスンで Chocolatey が導入済みであること
- 考えなくてよいこと: ファイルの中身と拡張子の使い分け。`memo.txt` に1行あれば十分です

## まとめ

持ち帰りは3つです。

1. VSCode は**部門の正規手順（Chocolatey 経由のカスタマイズ版）**で入れる
2. 画面で見る場所は**アクティビティバー・エクスプローラー・エディタ**の3つだけ
3. VSCode は**フォルダごと開いて**使う

これで、はじめにシリーズは完走です。環境準備は地味ですが重要です。手に入れた武器は Chocolatey と VSCode——この先のすべての作業の土台です。曼陀羅では **Git基礎シリーズと Python基礎シリーズが解放されました**。どちらから攻めるかは、あなたが決めてください。

2. 「新しく作ったファイルに文字を打ち込んでいる場所」は、画面の3つの場所のうちどれでしょうか。本文の表で確かめてください。
