# Chocolatey のセットアップ

## 学習目標

環境準備の最初のクエストです。ここでは **Chocolatey（チョコラティ）** を社内の申請システムから導入します。インストール作業は「面倒だから後で」と積み残されがちですが、今日手を動かすのは申請1件、10分だけです。いま済ませてしまいましょう。

終わる頃には、Chocolatey が何者で、なぜ VSCode より先にこれを入れるのかが分かっています。

## Chocolatey とは何か

Chocolatey は Windows 用の**パッケージマネージャー**です。難しそうな言葉ですが、たとえるなら**欲しいソフトをまとめて申し込める窓口**です。ソフトごとに配布サイトを探してインストーラーをダウンロードして……と自分で回らなくても、窓口に名前を伝えれば導入から更新まで面倒を見てくれます。

_出典: [Chocolatey 公式サイト](https://chocolatey.org/)（2026年8月取得）_

このトレーニングで Chocolatey が窓口になるのは次の2つです。

| これから入れるもの                      | 使うシリーズ                        |
| --------------------------------------- | ----------------------------------- |
| VSCode（拡張性の高いコードエディタ）    | Git基礎シリーズ・Python基礎シリーズ |
| uv（Python を動かす環境を整えるツール） | Python基礎シリーズ                  |

つまり、この先の道具はすべてこの窓口から受け取ります。だから環境準備の一番手に置かれています。

## IT Service Portal から申請する

Chocolatey 自体は、社内の **IT Service Portal** から申請して入れます。手順は次のとおりです。

1. IT Service Portal を開く
2. 「**SW install**」の項目を選ぶ
3. 対象として**自分の PC** を選ぶ
4. 検索欄で「**Chocolatey**」を検索し、選択する
5. 申請ボタンをクリックする

> **社内**: IT Service Portal の開き方と承認通知。答えるべき問い —
>
> - どこからアクセスするか（社内ポータルのリンク名・URL・デスクトップアイコンなど）
> - ログインに追加の認証が要るか
> - 申請が承認されたとき、通知（メールなど）は届くか。届くなら何がどこに届くか
>   形式: 手順1の直後に補う1〜3文 / 100〜150字

> **社内画像**: IT Service Portal で Chocolatey を申請する一連の画面。差し込みは「画面が変わるごとに1枚」を目安に、上の手順1〜5の範囲を対象とする。最低限、ポータルの入口（アクセス直後の画面）・SW install の選択画面・Chocolatey を検索・選択した状態の申請画面の3枚。氏名・社員番号・PC の管理番号はマスクする

申請はこれで完了です。**承認までの目安は1日**。このレッスンの続きと次のレッスンは、翌営業日あたりで大丈夫です。

## 承認されたら、入っていることを確かめる

承認されると、Chocolatey は**自動でインストールされます**。追加の操作はありません。

入ったことを一度だけコマンドで確かめます。スタートメニューで「PowerShell」を検索して開き、次を実行してください。

```powershell
choco --version
```

バージョン番号（数字の並び）が1行表示されれば導入完了です。もしエラーになったら、PowerShell を開き直してから再実行し、それでも駄目なら画面の文言をそのまま AI に貼って聞いてみてください——それでも解決しなければ、Teams の **DX Tools Training** チャンネルへどうぞ。環境のトラブルは遠慮なくすぐ聞いてかまいません。

## やってみる

IT Service Portal から Chocolatey の申請を出してください。承認された頃（翌営業日が目安）に、`choco --version` を実行して結果を確かめます。

- 前提: 社用 PC で申請すること
- 考えなくてよいこと: Chocolatey のコマンドの使い方。`choco` コマンドをこの確認以外で打つ場面は、このトレーニングにはありません

## まとめ

このレッスンの持ち帰りは3つです。

1. Chocolatey は**欲しいソフトをまとめて申し込める窓口**（パッケージマネージャー）
2. 申請は IT Service Portal の **SW install** から。**承認まで約1日**かかる
3. 承認後は**自動で入る**ので、`choco --version` で確認するだけ

承認を待つ間も冒険は止まりません。曼陀羅で解放済みの AI基礎シリーズへ先に進むのも良い選択です。
