## Requirements
### Requirement: 3階層ツリーで全コンテンツを表示する

ワークスペースの左端ペインは、シリーズ → コース → レッスンの3階層ツリーを単一ペインで表示しなければならない（SHALL）。シリーズ行・コース行は開閉 chevron を持ち、chevron クリックは開閉のみ（トグル）を行い選択を変更してはならない（MUST NOT）。**シリーズ・コース行の本体クリックは2段構え**としなければならない（SHALL）: **未選択の行**のクリックは「当該エンティティの選択」を行い、行が閉じているときに限り展開する——選択目的のクリックで開いている行を折りたたんではならない（MUST NOT）。**選択済みの行**の再クリックは開閉をトグルする（SHALL）。閉じていた行を展開したとき、下位階層の開閉状態は畳む前の状態を保持しなければならない（SHALL）。レッスン行のクリックは当該レッスンを選択し、Pane3 に本文を表示する（SHALL）。選択はクリックした階層で止まり、下位階層を自動選択してはならない（MUST NOT）。デザイン・行の視覚パターンは EBEX の `FileTreePane` を基調とする（SHALL）。ただしホバー・カーソル背景の濃度は「見た目」要件の定めに従い EBEX 同値としない。

シリーズが 0 件のときは、右クリック（空きスペースメニュー）からシリーズを追加するよう案内する空状態を表示しなければならない（SHALL）。

#### Scenario: 3階層が1ペインで見える

- **WHEN** シリーズ・コース・レッスンが存在する状態でワークスペースを表示する
- **THEN** 左端ペインにシリーズ → コース → レッスンの階層ツリーが表示され、旧ペイン2（レッスン一覧の独立ペイン）は存在しない

#### Scenario: chevron は開閉だけを行う

- **WHEN** コースを選択した状態で別シリーズの chevron をクリックする
- **THEN** そのシリーズが開閉されるだけで、選択中のコースは変わらない

#### Scenario: 未選択の開いているシリーズのクリックは畳まない

- **WHEN** 別の階層を選択した状態で、開いているシリーズの行本体をクリックする
- **THEN** そのシリーズが選択され（コース・レッスンの選択はクリアされ）、シリーズは開いたままである

#### Scenario: 選択済みのシリーズの再クリックはトグルする

- **WHEN** 選択済みの開いているシリーズの行本体をもう一度クリックする
- **THEN** そのシリーズが折りたたまれる
- **AND** さらにもう一度クリックすると展開する

#### Scenario: 閉じているシリーズのクリックは展開し子の状態を保つ

- **WHEN** 配下のコースを畳んだ状態でシリーズを畳み、そのシリーズの行本体をクリックする
- **THEN** シリーズが展開し、配下のコースは畳んだままである

#### Scenario: 子を開いたまま畳んだシリーズを開き直す

- **WHEN** 配下のコースを開いた状態でシリーズを畳み、そのシリーズの行本体をクリックする
- **THEN** シリーズが展開し、配下のコースは開いたままである

#### Scenario: レッスン行クリックで Pane3 が開く

- **WHEN** ツリーのレッスン行をクリックする
- **THEN** そのレッスンが選択され Pane3 に本文が表示される

#### Scenario: 0 件時の空状態

- **WHEN** シリーズが 0 件である
- **THEN** 右クリックでシリーズを追加できる旨の案内が表示され、旧フッターの追加ボタンは存在しない

### Requirement: 行の表示要素

ツリー行の表示要素は次のとおりとしなければならない（SHALL）: **シリーズ行**は名前の右端（右寄せ）に「完了レッスン数/総レッスン数」を青系の色で表示する（シリーズ配下の全レッスンを母数とする）。**コース行**は名前のみ。**レッスン行**は名前の左に file-text アイコンを青系の色（EBEX の markdown ファイルと同じ色クラス）で表示し、名前の右端（右寄せ）にステータスボタンを表示する。ステータスボタンのアイコンは `muted-foreground`（サブテキスト色）で表示しなければならない（SHALL）——行本文の前景色を継承させない。進捗バー・行内の編集鉛筆ボタン・dashed 全幅の追加ボタンを表示してはならない（MUST NOT）。

行の強調は次の規則に従わなければならない（SHALL）: **太字は選択中の行のみ**（シリーズ行を常時太字にしてはならない。MUST NOT）。**背景色はキーボードカーソル行・コンテキストメニュー対象行・ホバーのみ**に付け、選択自体を背景色で表現してはならない（MUST NOT）。

レッスンステータスは `open` / `in_progress` / `done` を用い、表示ラベルはそれぞれ未着手・作成中・完成としなければならない（SHALL）。ステータスボタンのクリックは `open` → `in_progress` → `done` → `open` の順で循環し、行選択を発生させてはならない（MUST NOT）。ステータス更新時は当該レッスンの保存済みステータス（現行の保存層では `contents.md` フロントマターの `status`）を同期しなければならない（SHALL）。

#### Scenario: シリーズ行のレッスン数表示

- **WHEN** 配下に完了2件を含む全5レッスンを持つシリーズを表示する
- **THEN** シリーズ行の右端に「2/5」が青系の色で表示され、進捗バーは表示されない

#### Scenario: レッスン行のアイコン

- **WHEN** レッスン行を表示する
- **THEN** 名前の左に青系の file-text アイコンが表示される

#### Scenario: ステータスアイコンがサブテキスト色である

- **WHEN** ステータスが異なる複数のレッスン行を表示する
- **THEN** すべてのステータスアイコンが `muted-foreground` のグレーで表示され、状態の違いはアイコンの形で判別できる

#### Scenario: 選択行だけが太字になる

- **WHEN** コースを選択する
- **THEN** そのコース行だけが太字になり、シリーズ行・他の行は通常の太さで表示される

#### Scenario: ステータスクリックが選択を変えない

- **WHEN** 別のレッスンを選択した状態で、あるレッスン行のステータスボタンをクリックする
- **THEN** そのレッスンのステータスが次の状態へ循環する
- **AND** 選択中のレッスンは変わらない

#### Scenario: ステータスが保存層と同期する

- **WHEN** レッスンのステータスボタンをクリックして `done` にする
- **THEN** 当該レッスンの保存済みステータスも `done` に更新される

### Requirement: 右クリックコンテキストメニュー

ツリーは右クリック対象の型ごとに次のコンテキストメニューを表示しなければならない（SHALL）:

| 対象 | 項目（この順） |
|---|---|
| シリーズ行 | add course / rename / copy / paste / open explorer / delete |
| コース行 | add lesson / rename / copy / paste / open explorer / delete |
| レッスン行 | rename / copy / open explorer / delete |
| 空きスペース・ホーム行・検索行の余白 | add series / collapse all / paste / open explorer |

- **properties をメニューに含めてはならない（MUST NOT）**——メタ編集は選択時のペイン2 ビュー（全体／シリーズ／コース）とペイン2 ヘッダーの鉛筆（レッスン）が担う
- paste はクリップボードに受け入れ可能な型があるときだけ活性化する（シリーズ行にはコース、コース行にはレッスン、空きスペース・ホーム行にはシリーズ。SHALL）
- open explorer は当該フォルダ（空きスペース・ホーム行は `contents/`）を OS のファイルマネージャで開く
- **collapse all は全シリーズ・全コースを折りたたむ。ただし現在の選択へ至る祖先は開いたまま残す**（SHALL）
- delete は既存の削除確認ダイアログを経由する（SHALL）
- ステータス変更の項目をメニューに含めてはならない（MUST NOT）——行内ボタンで完結する
- **キーボード（Shift+F10・メニューキー）でカーソル行のコンテキストメニューを開けなければならない**（SHALL）。メニューはカーソル行の位置に表示する
- **検索行の余白（入力欄以外）の右クリック**は空きスペースと同じメニューを表示しなければならない（SHALL）。検索入力欄そのものではブラウザ標準のテキストメニュー（貼り付け等）を維持しなければならない（SHALL）

メニュー操作直後のポインター操作が行の開閉・選択として誤発火してはならない（MUST NOT）。

#### Scenario: コース行のメニュー構成

- **WHEN** コース行を右クリックする
- **THEN** add lesson / rename / copy / paste / open explorer / delete がこの順で表示される

#### Scenario: properties はどのメニューにも無い

- **WHEN** シリーズ行・コース行・レッスン行・空きスペースをそれぞれ右クリックする
- **THEN** いずれのメニューにも properties は表示されない

#### Scenario: paste の活性制御

- **WHEN** レッスンを copy した状態でシリーズ行を右クリックする
- **THEN** paste は非活性である（シリーズ行が受け入れるのはコースのみ）

#### Scenario: 空きスペースからシリーズを追加する

- **WHEN** ツリーの空きスペースを右クリックして add series を選ぶ
- **THEN** シリーズ追加ダイアログが開く

#### Scenario: collapse all が選択への道だけ残す

- **WHEN** あるレッスンを選択した状態で空きスペースメニューの collapse all を実行する
- **THEN** 選択レッスンの祖先（シリーズ・コース）以外のすべてのシリーズ・コースが折りたたまれる

#### Scenario: Shift+F10 でカーソル行のメニューが開く

- **WHEN** コース行にキーボードカーソルがある状態で Shift+F10 を押す
- **THEN** そのコース行のコンテキストメニューがカーソル行の位置に表示される

#### Scenario: 検索行の余白から右クリックする

- **WHEN** 検索入力欄の外側（検索行の余白）を右クリックする
- **THEN** 空きスペースと同じメニュー（add series / collapse all / paste / open explorer）が表示される

#### Scenario: 検索入力欄はブラウザ標準メニューのまま

- **WHEN** 検索入力欄の中を右クリックする
- **THEN** ブラウザ標準のテキスト編集メニューが表示される

### Requirement: 同一階層内の DnD 並べ替え

ツリーは同じ親に属する兄弟ノード間のドラッグ＆ドロップ並べ替えを提供しなければならない（SHALL）。並べ替えの確定は既存の並び順永続化（`.meta.json` の `order` 更新）を用いなければならない（SHALL）。異なる親への移動（階層またぎ）を DnD で行えてはならない（MUST NOT）。

#### Scenario: コースを同一シリーズ内で並べ替える

- **WHEN** シリーズ内のコースをドラッグして兄弟の間にドロップする
- **THEN** シリーズ `.meta.json` の `order` が新しい並びで保存される

#### Scenario: 階層またぎはドロップできない

- **WHEN** レッスンを別コースの上へドラッグする
- **THEN** ドロップは受け付けられず、並びは変わらない

### Requirement: 複製（copy / paste）

copy はクリップボード（クライアント内 state）に対象の型とパスを記録し、paste は受け入れ先に**複製**を作成しなければならない（SHALL）。複製は `POST /api/content/duplicate` を通じて行い、複製後のエンティティは次を満たさなければならない（SHALL）:

- 名前は「元の名前（コピー）」。衝突時は「（コピー2）」以降の連番
- `id` を持たない状態で作成され、ローダーの自動採番で新しい `id` が発行される
- `slug` を持たない（人が後で設定する——slug 重複による公開サイトビルド中断を構造的に防ぐ）
- 本文・その他のメタフィールドは元の内容を保持する

#### Scenario: レッスンを複製する

- **WHEN** レッスン「最初のコミット」を copy し、同じコースに paste する
- **THEN** 「最初のコミット（コピー）」が作成され、本文は元と同一である
- **AND** 新しい `id` が採番され、`slug` は未設定である

#### Scenario: 名前の衝突は連番で回避する

- **WHEN** 「最初のコミット（コピー）」が既に存在する状態で同じレッスンを paste する
- **THEN** 「最初のコミット（コピー2）」が作成される

### Requirement: ホーム行

ツリーの最上部にホーム行を表示しなければならない（SHALL）。ホーム行は lucide `house` アイコンとラベルを持ち、インデント・ガイド線の外に置く（SHALL）。クリックで全体（ホーム）を選択しなければならない（SHALL）——選択状態はシリーズ・コース・レッスンすべて未選択で表す。選択中のホーム行はラベルを太字で表示しなければならない（SHALL）。ホーム行の右クリックは空きスペースと同じコンテキストメニューを表示しなければならない（SHALL）。

ホーム行のラベルは**編集言語に従わなければならない**（SHALL）——日本語ビューは `ホーム`、英語ビューは `Home`。英語ビューの語は `workspace-meta-views` capability が定めるペイン2 ヘッダーの階層種別ラベル（`root` の英語語彙）と**同一の値を用いなければならない**（SHALL）——`Home` の文字列を別途定義してはならない（SHALL NOT）。日本語ビューのラベルは `ホーム` を維持しなければならない（SHALL）——階層種別ラベルの日本語（`全体`）に合わせて対称化してはならない（SHALL NOT）。

ホーム行のラベルに全体メタの `name` / `name_en`（ワークスペース名）を表示してはならない（SHALL NOT）——ホーム行はナビゲーションの原点であり、シリーズ・コース・レッスン行のようなコンテンツ名の表示行ではない。

#### Scenario: ホームを選択する

- **WHEN** ツリー最上部のホーム行をクリックする
- **THEN** シリーズ・コース・レッスンの選択がすべて解除され、ホーム行のラベルが太字になる

#### Scenario: ホーム行の右クリック

- **WHEN** ホーム行を右クリックする
- **THEN** 空きスペースと同じメニュー（add series / collapse all / properties / paste / open explorer）が表示される

#### Scenario: 日本語ビューのホーム行ラベル

- **WHEN** 編集言語が日本語の状態でツリーを表示する
- **THEN** ホーム行のラベルは `ホーム` である

#### Scenario: 英語ビューのホーム行ラベル

- **WHEN** 編集言語を英語へ切り替える
- **THEN** ホーム行のラベルは `Home` になり、ペイン2 ヘッダーの階層種別ラベルと同じ語で一致する

#### Scenario: ワークスペース名は出さない

- **WHEN** 全体メタに `name_en` が設定された状態で英語ビューを表示する
- **THEN** ホーム行のラベルは `Home` のままで、`name_en` の値は表示されない

### Requirement: キーボード操作

ツリーはフォーカス中の行を示すキーボードカーソルを持ち、次のキー操作を提供しなければならない（SHALL）:

- `↑` / `↓`: 可視行（ホーム行・シリーズ・コース・レッスン）の間でカーソルを移動する
- `→`: カーソル行がシリーズ・コースで閉じているとき展開する
- `←` / `Backspace`: カーソル行が開いているシリーズ・コースなら折りたたみ、それ以外なら親階層の行へカーソルを移す
- `Enter`: 行クリックと同じ動作（シリーズ・コース＝未選択なら選択＋閉じているときのみ展開・選択済みならトグル、レッスン＝選択、ホーム＝全体選択）
- `F2`: カーソル行のリネームダイアログを開く（ホーム行は対象外）
- `Delete`: カーソル行の削除確認ダイアログを開く（ホーム行は対象外）
- `Home` / `End`: 先頭行・末尾行へ移動する
- `Ctrl+C` / `Ctrl+V`: カーソル行を copy / カーソル行を受け入れ先として paste（複製）する。受け入れ可否は右クリックメニューの paste と同じ規則に従う

カーソル行は背景色で強調し、`scrollIntoView` で可視範囲に追従させなければならない（SHALL）。カーソル行が絞り込み・折りたたみ・削除で不可視になったときは、生きている可視行へカーソルを付け替え、キーボード操作を継続できなければならない（SHALL）。**選択がツリー外の操作（ミニ曼陀羅・全体曼陀羅のノードクリック等）で変わったときも、カーソルを選択行へ追随させなければならない**（SHALL）——太字（選択）と背景（カーソル）がずれたままになってはならない（MUST NOT）。ただしこの追随で DOM フォーカスを移してはならない（MUST NOT）——開いているモーダルやエディタからフォーカスを奪うため。ダイアログ表示中はツリーのキー操作を無効にしなければならない（MUST NOT 発火）。

#### Scenario: 矢印キーで移動して Enter で選択する

- **WHEN** ツリーにフォーカスがある状態で `↓` を数回押しレッスン行にカーソルを合わせ、`Enter` を押す
- **THEN** そのレッスンが選択され Pane3 に本文が表示される

#### Scenario: Enter は未選択の開いている行を畳まない

- **WHEN** 別の階層を選択した状態で、開いているシリーズ行にカーソルを合わせ `Enter` を押す
- **THEN** そのシリーズが選択され、開いたままである

#### Scenario: Enter は選択済みの行ではトグルする

- **WHEN** 選択済みの開いているシリーズ行にカーソルがある状態で `Enter` を押す
- **THEN** そのシリーズが折りたたまれる

#### Scenario: F2 でリネームダイアログが開く

- **WHEN** コース行にカーソルがある状態で `F2` を押す
- **THEN** コース名の変更ダイアログが現在名入りで開く

#### Scenario: Backspace で親へ畳む

- **WHEN** レッスン行にカーソルがある状態で `Backspace` を押す
- **THEN** カーソルが親のコース行へ移動する

#### Scenario: Ctrl+C / Ctrl+V で複製する

- **WHEN** レッスン行で `Ctrl+C` を押し、同じコースの行で `Ctrl+V` を押す
- **THEN** 当該コースにレッスンの複製（「（コピー）」名）が作成される

#### Scenario: カーソル行が消えても操作が続けられる

- **WHEN** コース行にカーソルがある状態でそのシリーズを chevron で畳む
- **THEN** カーソルは可視の行（畳んだシリーズ行）へ移り、続けて `↑` / `↓` が機能する

#### Scenario: 曼陀羅からの遷移にカーソルが追随する

- **WHEN** ミニ曼陀羅または全体曼陀羅のノードをクリックして別のコースへ遷移する
- **THEN** ツリーの太字（選択）と背景（カーソル）がどちらも遷移先の行へ移る
- **AND** 開いている曼陀羅モーダルはフォーカスを奪われない

### Requirement: 検索

ヘッダーの下に常設の検索入力行を表示しなければならない（SHALL）。入力に応じてツリーを絞り込む:

- 通常の入力は**名前フィルタ**として、シリーズ・コース・レッスン名の部分一致（大文字小文字無視）でツリーを絞り込む（SHALL）。一致ノードの祖先は表示を維持し、一致したシリーズ・コースの配下は表示する（SHALL）
- `?` で始まる入力は**コンテンツ全文検索**として、`contents/` を対象にした検索 API に問い合わせ、一致したレッスン等のキー集合でツリーを絞り込む（SHALL）。問い合わせは 300ms のデバウンスを挟み、検索中の表示を出す（SHALL）。一致が 200 件を超えたときは絞り込みを促すメッセージを表示する（SHALL）
- 入力があるときはクリアボタン（×）を表示し、クリックでフィルタと検索状態を消去する（SHALL）
- EBEX のお気に入りトグルは移植しない——検索行にお気に入りボタンを表示してはならない（MUST NOT）

**検索対象は編集言語に連動しなければならない**（SHALL）:

| モード | 名前の照合 | 本文の照合（中身検索） |
|---|---|---|
| 日本語 | 日本語名 | `contents.md` |
| 英語 | **`name_en` と日本語名の両方** | `contents.en.md` |

英語モードで名前を両言語照合するのは、ツリーが未訳ユニットを日本語名フォールバックで表示するため（SHALL）——**画面に見えている文字列で検索してヒットしない状態を作ってはならない**（MUST NOT）。名前フィルタの照合規則は表示名の解決（`studio-translation` のヘルパー）と同じ土台を使い、表示と検索がずれない構造にする（SHALL）。

英語モードの本文照合で、`contents.en.md` が無いレッスンの日本語本文へフォールバックしてはならない（SHALL NOT）——英語ビューに存在しない一致でツリーを絞り込むと、開いた先でハイライトが空振りする。英語の本文が無いレッスンは本文ではヒットしない。

検索 API は言語パラメータ（省略時 `ja`）を受け取らなければならない（SHALL）——日本語モードの検索挙動はこの要件の変更前と同一に保つ（SHALL）。

#### Scenario: 名前フィルタで絞り込む

- **WHEN** 検索入力に「Git」と入力する
- **THEN** 名前に「Git」を含むノードとその祖先・配下だけがツリーに表示される

#### Scenario: 全文検索で絞り込む

- **THEN** 本文に「コミット」を含むレッスンだけが（祖先と共に）ツリーに表示される

- **THEN** `name_en` に「Basics」を含むユニットがツリーに表示される

#### Scenario: 英語モードでも未訳は日本語名でヒットする

- **THEN** そのレッスンがツリーに表示される

#### Scenario: 英語モードの中身検索は英語本文を引く

- **THEN** `contents.en.md` に「repository」を含むレッスンだけが表示され、`contents.en.md` の無いレッスンは日本語本文に同語があっても表示されない

#### Scenario: クリアで全件に戻る

- **THEN** 入力が空になり、ツリーが全件表示に戻る

### Requirement: 見た目の EBEX パリティ

ツリーの見た目は次を満たさなければならない（SHALL）:

- **青い縦レール**: 現在の選択（ホーム選択を除く）を含むシリーズブロックの左辺に、primary 色の縦レール（`before:` 疑似要素・約3px）を表示する。DnD のドロップ対象表示中はレールを出さない
- **ガイド線**: シリーズ→コース、コース→レッスンの子コンテナ左辺に `border-border` の縦ガイド線を表示する（EBEX と同じ `border-l` 方式）。線の水平位置は**親行のアイコン中心のやや左**（EBEX の FileTreePane と同じ相対関係）を通るよう、行の左右インセットに合わせて調整しなければならない（SHALL）
- **階層の区間幅**: 「レール→シリーズのガイド線」「シリーズのガイド線→コースのガイド線」「コースのガイド線→レッスンのアイコン」の 3 区間は、**ほぼ等幅**（差 1px 以内）でなければならない（SHALL）。揃えるときはシリーズのガイド線とレールを動かさず、子コンテナの線から行までの距離で調整する（SHALL）。ガイド線と行の中身（シェブロン・アイコン）の間には行の左余白ぶんの隙間が残らなければならない（SHALL）
- **グレーヘッダー**: ペイン1 のヘッダー行はページ背景色（`bg-background`）で塗る——EBEX のペイン1 と同じ見え方にする
- **ホバー・カーソル背景の濃度**: ライトテーマは**ペイン2 編集ビューのカーソル行と同じ濃度**（`muted` 50% を背景に混色）としなければならない（SHALL）——2026-08-18 に「前景4%が下限」とした決定は上書きし、編集行と同じグレーに統一する（2026-08-19）。ダークテーマは前景 6.5% 混色を維持する（SHALL）。いずれも EBEX（ライト前景7%混色／ダーク10%混色）より薄い
- **フォーカスリング非表示**: ツリー内のキーボード操作・クリックで、行・行内ボタンに青いフォーカスリング（outline / ring）を表示してはならない（MUST NOT）。カーソル位置は背景色のみで表現する

- **THEN** そのシリーズブロックの左辺に primary 色の縦レールが表示され、他のシリーズには表示されない

- **THEN** コース群・レッスン群の左辺に縦のガイド線が表示され、線は親行のアイコン中心のやや左を通る

#### Scenario: 3 区間がほぼ等幅である

- **WHEN** 選択を含むシリーズを展開し、その中のコースも展開する
- **THEN** レールからシリーズのガイド線、シリーズのガイド線からコースのガイド線、コースのガイド線からレッスンのアイコンまでの 3 つの幅の差は 1px 以内である
- **AND** ガイド線とシェブロン・アイコンの間には隙間がある

#### Scenario: 矢印キーで青枠が出ない

- **WHEN** ツリーにフォーカスがある状態で `↑` `↓` `→` `←` を操作する
- **THEN** どの行・ボタンにも青いフォーカスリングは表示されず、カーソル行は背景色だけで示される

#### Scenario: ライトのカーソル行が編集行と同じ濃度である

- **WHEN** ライトテーマでツリー行にホバーし、同じレッスンを編集ビューで開いてカーソル行を表示する
- **THEN** ツリー行の背景と編集ビューのカーソル行の背景は同じ濃度のグレーである

### Requirement: ペインヘッダーと折りたたみ時レイアウト

ペイン1 の展開時、ヘッダー行にはロゴアイコンとワークスペース名のみを表示し、ペイン折りたたみトグルは**検索行の右端**に置かなければならない（SHALL）。ペイン折りたたみ時（アイコン幅）は、ヘッダー行にロゴアイコンのみを表示し、**本文領域の最上部に展開ボタン**を表示しなければならない（SHALL）。折りたたみ時に検索入力・ツリー本体を表示してはならない（MUST NOT）。

ヘッダーのロゴアイコンとワークスペース名は**ホームへの入口**を兼ねなければならない（SHALL）——クリックでホームを選択し、ツリーのキーボードカーソルもホーム行へ移す（ホーム行のクリックと同じ動作）。折りたたみ時もロゴアイコンのクリックで同じ動作をしなければならない（SHALL）。

ホバー時は**不透明度をわずかに下げる**ことで押せることを示さなければならない（SHALL）——公開サイトの左上ロゴ（テーマ既定の `hover:opacity-75`）と同じ言葉遣いに揃える。文字色・背景・装飾を変えてはならない（MUST NOT）——見出しとしての佇まいを保つ。あわせてホバー時のマウスカーソルはポインタでなければならない（SHALL）。

#### Scenario: 展開時のトグル位置

- **WHEN** ペイン1 が展開されている
- **THEN** 検索行の右端に折りたたみトグルが表示され、ヘッダー行にはロゴとワークスペース名だけが表示される

#### Scenario: 折りたたみ時のレイアウト

- **WHEN** ペイン1 を折りたたむ
- **THEN** ヘッダーにはロゴアイコンのみが表示され、その下の本文最上部に展開ボタンが表示される
- **AND** 検索入力とツリーは表示されない

#### Scenario: ヘッダーからホームへ戻る

- **WHEN** コースを選択している状態でヘッダーのワークスペース名をクリックする
- **THEN** ペイン2 が全体メタフォームに切り替わり、ツリーのホーム行が選択状態（太字）になる

#### Scenario: ヘッダーはホバーでわずかに薄くなる

- **WHEN** ヘッダーのロゴまたはワークスペース名にマウスを乗せる
- **THEN** ロゴとワークスペース名がまとめてわずかに薄くなり、マウスカーソルがポインタに変わる
- **AND** 文字色・背景・装飾は変化しない

### Requirement: ツリーの開閉状態を再起動をまたいで保持する

ツリーの開閉状態は **cookie** に保存し、起動・リロード時に復元しなければならない（SHALL）。毎回すべてを展開した状態で開いてはならない（MUST NOT）。

復元は**サーバーの初期描画**で行わなければならない（SHALL）——サーバーが cookie を読み、畳んだ状態の HTML を返す。**全展開のツリーが一瞬でも表示されてはならない**（MUST NOT）——サーバーが描いた HTML は hydration まで表示され続け、クライアント側の復元（`useState` 初期化関数・`useEffect`・`useLayoutEffect` のいずれも）は hydration の前に走らないため、クライアント側の復元では満たせない。

保存するのは**折りたたまれているシリーズ・コースの ID の集合**でなければならない（SHALL）。展開されている ID を保存してはならない（MUST NOT）——追加・同期で新しく現れたシリーズ・コースが展開状態で現れる現在の挙動を保つため。保存されていない ID は展開として扱う（SHALL）。

**記憶が無いときは、すべてのシリーズ・コースを折りたたんだ状態で描画しなければならない**（SHALL）——cookie が存在しない初回起動と、cookie の失効・破損がこれに当たる。⚠ 「記憶が無い」と「cookie はあるが畳んだ ID が0件」を区別しなければならない（SHALL）: 前者は記憶が無い状態で全折りたたみ、後者は「すべて展開している」という記憶であり全展開で描く。

保存は開閉が変わるたびに行わなければならない（SHALL）。書き込みに失敗しても操作を中断してはならない（MUST NOT）。

#### Scenario: 畳んだ状態がリロード後も残る

- **WHEN** あるシリーズと別のコースを折りたたみ、Studio をリロードする
- **THEN** そのシリーズとコースは折りたたまれた状態で表示される
- **AND** 畳んでいなかったシリーズ・コースは展開された状態で表示される

#### Scenario: サーバーが返す HTML が既に畳まれている

- **WHEN** あるシリーズを折りたたんだ状態で、ページの HTML をサーバーから取得する
- **THEN** その HTML にそのシリーズ配下のコース行は含まれない

#### Scenario: 新しく現れたシリーズは展開される

- **WHEN** 保存された折りたたみ状態がある状態で、新しいシリーズがディスク上に追加されて読み込まれる
- **THEN** そのシリーズは展開された状態で表示される

#### Scenario: cookie が無い初回は全折りたたみ

- **WHEN** ツリーの開閉の cookie が存在しない状態で Studio を開く
- **THEN** すべてのシリーズ・コースが折りたたまれた状態で表示される
- **AND** 最初にサーバーから返る HTML の時点で畳まれている

#### Scenario: すべて展開した記憶は全展開で復元する

- **WHEN** すべてのシリーズ・コースを展開した状態（畳んだ ID が0件）の cookie がある状態で Studio を開く
- **THEN** すべてのシリーズ・コースが展開された状態で表示される

### Requirement: 復元時は選択中のアイテムの祖先を展開する

保存された折りたたみ状態から復元したとき、**選択中のシリーズ・コースおよびその祖先は展開されていなければならない**（SHALL）——選択されているアイテムが畳まれた枝の中に隠れた状態で開始してはならない（MUST NOT）。

これを満たすため、**保存する集合から選択中のシリーズ・コースを除かなければならない**（SHALL）。選択が変わったときも保存し直す（SHALL）——サーバーは選択を知らないので、保存する側が先に除いておく。

この扱いは**復元の一度きり**でなければならない（SHALL）。復元後にユーザーが選択中の行を折りたたむ操作を妨げてはならない（MUST NOT）——選択済みの行の再クリックで折りたたむ既存の2段構えの挙動を保つ。

**開閉の記憶が無いときは本要件は働かない**（SHALL）——そのときは選択の cookie も無いため、選択を**ホーム**にしなければならない（SHALL）。⚠ 選択を先頭レッスンのフォールバックに落としてはならない（MUST NOT）——落とすと本要件によってその祖先が展開され、「1本だけ道が開いた全折りたたみ」になって「記憶が無いときは全折りたたみ」を満たせなくなる。

⚠ **この抑止はクライアント側にも効かせなければならない**（SHALL）。ツリーは、サーバー描画の後に届いた選択に対しても祖先を開く保険を持つが、**開閉の記憶が無かったときはその保険を働かせてはならない**（MUST NOT）。開閉は cookie、選択はクライアントの `localStorage` にも保持されるため、**cookie だけが失効して選択が生きている状態**が起こりうる。抑止しないと、そのとき「1本だけ枝が開いた全折りたたみ」になる。そのため、開閉の初期値が記憶から来たのか記憶が無くて組んだのかを、ツリーへ伝えなければならない（SHALL）。

#### Scenario: 選択中のレッスンの祖先が開く

- **WHEN** あるレッスンを選択した状態でその親シリーズと親コースを折りたたみ、Studio をリロードする
- **THEN** 親シリーズと親コースは展開され、選択中のレッスンが見える

#### Scenario: 記憶が無いときはホームが選択される

- **WHEN** ツリーの開閉と選択の cookie がいずれも存在しない状態で Studio を開く
- **THEN** 選択はホームであり、展開されているシリーズ・コースは1つも無い

#### Scenario: cookie だけ失効し選択が残っていても全折りたたみ

- **WHEN** 開閉の cookie が無く、クライアントの `localStorage` にだけ前回の選択が残っている状態で Studio を開く
- **THEN** 展開されているシリーズ・コースは1つも無い
- **AND** 届いた選択の祖先を開く保険は働かない

#### Scenario: 復元後は選択中の行も畳める

- **WHEN** 上記の復元の直後に、選択中のレッスンの親コース行を折りたたむ
- **THEN** そのコースは折りたたまれる

#### Scenario: 選択と無関係な枝は畳まれたまま

- **WHEN** 選択中のレッスンの祖先ではないシリーズを折りたたんだ状態でリロードする
- **THEN** そのシリーズは折りたたまれたままである

#### Scenario: 保存値に選択の祖先は含まれない

- **WHEN** あるレッスンを選択した状態で、その親シリーズを折りたたむ
- **THEN** 保存される集合にその親シリーズの ID は含まれない

### Requirement: 実在しないエンティティの保存値を破棄する

保存された折りたたみ状態を読み込むとき、**現在のコンテンツに存在しないシリーズ・コースの ID を捨てなければならない**（SHALL）。リネーム・削除で失われた ID を保存し続けてはならない（MUST NOT）。

保存値が壊れている（JSON として読めない・想定の形でない）場合はエラーにせず、**記憶が無い状態として扱わなければならない**（SHALL）——すなわち全折りたたみで描画する。⚠ 「畳んだ ID が0件の正しい保存値」と同じ扱いにしてはならない（MUST NOT）。壊れた値は記憶の喪失であり、「すべて展開している」という記憶ではない。

#### Scenario: 削除されたシリーズの ID を捨てる

- **WHEN** 保存値に既に存在しないシリーズの ID が含まれた状態で Studio を開く
- **THEN** その ID は無視され、実在するシリーズ・コースの開閉だけが復元される

#### Scenario: 壊れた保存値は記憶なしとして扱う

- **WHEN** cookie の値が JSON として読めない状態で Studio を開く
- **THEN** エラーにならず、すべてのシリーズ・コースが折りたたまれた状態で表示される

### Requirement: collapse all は選択自身を畳む

collapse all が開いたまま残すのは選択の**祖先**だけでなければならない（SHALL）。選択中のシリーズ行・コース行自身は他のノードと同様に畳まなければならない（SHALL）——行自体は畳んでも表示され続けるため、選択の可視性は祖先の展開だけで保たれる。

collapse all の実行によって、折りたたみ済みのノードが展開されてはならない（MUST NOT）。

#### Scenario: 折りたたみ済みの選択中シリーズが展開されない

- **WHEN** 折りたたんだ状態のシリーズを選択し、空きスペースメニューの collapse all を実行する
- **THEN** そのシリーズは折りたたまれたままである

#### Scenario: 選択中のコース自身も畳まれる

- **WHEN** 展開した状態のコースを選択し、collapse all を実行する
- **THEN** そのコースは畳まれ、祖先のシリーズだけが開いたまま残る

#### Scenario: レッスン選択時は祖先が開いたまま残る

- **WHEN** あるレッスンを選択した状態で collapse all を実行する
- **THEN** 選択レッスンの祖先（シリーズ・コース）だけが開いたままで、それ以外のすべてのシリーズ・コースが折りたたまれる

### Requirement: collapse all はカーソルを選択中の行へ移す

collapse all の実行後、キーボードカーソル（背景のハイライト）は**選択中の行**になければならない（SHALL）。

メニューを開いた時点でカーソルは右クリックした場所へ移っており、空きスペースから実行したときはカーソルの位置が行ですらない。畳んだ後のカーソルを既定の付け替え（可視の先頭行＝ホーム行）に委ねてはならない（MUST NOT）——選択と無関係なホーム行がハイライトされ、選択の在り処が分からなくなる。

選択の祖先は開いたまま残るため、選択中の行は畳んだ後も必ず可視である。

#### Scenario: 空きスペースから実行してもホームがハイライトされない

- **THEN** 背景のハイライトは選択中のレッスン行に付く
